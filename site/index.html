    いつものAIをそのまま

    いつものAIに繋げて使う、
    シンプルな会計バックエンド。

    OpenTaxが受け持つのは、帳簿・税制のルール・書類の保管といった会計の土台だけ。明細を読むのも、科目を考えるのも、あなたがすでに使っているAIの役割です。独自のAIを持たないので、AIの利用料を二重に払うことも、特定のAIに縛られることもありません。

    OpenTaxを動かすのに、AIサービスの契約やAPIキーは必要ありません。

    OpenTaxに入っていないもの

    • 独自のAI
    • 文字読み取り（OCR）
    • CSVの取込設定
    • 銀行ごとの連携
    • AIチャット
    • AI税務アシスタント

    OpenTaxが受け持つこと

    • 複式簿記の帳簿
    • 会計ルールのチェック
    • 日本の税制に沿った計算
    • 見積書・請求書
    • 証憑の保管
    • 変更履歴
    • 申告データの出力

    できる 工夫すれば一部できる 難しい

    一般的な使い方を比べたものです。実際の機能は製品や使い方によって異なります。電子帳簿保存法への完全な対応には、事務処理規程の作成などが別途必要です。OpenTaxはプレビュー版のため、帳簿や申告の内容は必ずご自身で確認してください。

    できること

    仕訳画面を、開かなくていい。

    やりたいのは画面の操作ではなく、帳簿を最新にしておくこと。いつものAIに話しかけるだけで、AIがOpenTaxを操作します。

    create_journals権限：仕訳の作成

    安心して任せるために

    AIに任せても、
    最後に決めるのはあなた。

    確認待ち

    AIが登録した仕訳は、すべて「確認待ち」から。

    あなたが確定するまで、帳簿には反映されません。AIは自信のない判断にメモを残すので、確認が必要なものだけを見れば済みます。

    AIが登録→確認待ち→確定

    権限

    AIごとに、できることを絞れる

    接続するAIごとに「読み取りだけ」「仕訳の作成まで」など権限を選べます。接続はいつでも解除できます。

    チェック

    1件ずつ確かめてから登録

    貸借が合わない、科目がおかしいといった誤りは、1件ずつ理由付きでAIに返します。同じ取引の二重登録も防ぎます。

    計算

    税額の計算にAIは使わない

    集計や税額は、決まったルールで計算します。同じ帳簿からは、いつでも同じ結果が出ます。

    履歴

    誰が何を変えたか残る

    仕訳の作成・修正・確定はすべて記録され、AIの操作か、あなたの操作かも区別できます。

    中身が見える会計ソフト

    何をしているか、
    すべて確かめられます。

    税金の計算方法も、その根拠も、まだできていないことも。OpenTaxのソースコードは、誰でも読むことができます。

    01

    ソースコードを公開

    帳簿も、税額の計算も、AIとの連携部分も、すべてGitHubで読めます。

    02

    計算はテストで確認

    会計・税制のロジックは自動テストで確かめており、何度計算しても同じ結果になります。

    03

    できないことも公開

    未対応の税制や既知の制限は、隠さずに一覧で公開していきます。

    04

    不具合は公開の場で修正

    計算の誤りの指摘は大歓迎です。修正内容と影響範囲をすべて記録します。

    開発者について

    OpenTaxは、税理士ではない個人の開発者がつくっています。

    だからこそ、すべてを公開しています。

    計算ロジック、その根拠、テスト、既知の制限を公開し、誰でも確認・指摘できるようにしています。開発にはAIも活用していますが、税額の計算は決まったルールのコードで行い、テストで確認しています。
    なお、OpenTaxは税務相談のサービスではありません。判断に迷うときは、税理士などの専門家や税務署にご相談ください。

    こんな方に

    AIと一緒に働く、
    ひとり事業者のために。

    OpenTaxは、すべての方に向けた会計ソフトではありません。合う方・合わない方を正直にお伝えします。

    ✓向いている方

    • Claude Code・Codex・Cursorなどを毎日使っている
    • 個人開発者・フリーランスのエンジニアやデザイナー
    • 小さなサービスをひとりで運営している
    • 会計もAIとのいつもの作業にまとめたい
    • 自分の環境でソフトを動かすことに抵抗がない

    —既存の会計ソフトのほうが合う方

    • AIエージェントをまだ使っていない
    • 電話やチャットでのサポートを重視したい
    • 税務の判断についても相談したい
    • 銀行口座をつなぐだけで全自動にしたい
    • 給与や勤怠までまとめて管理したい

    はじめかた

    3ステップで、
    AIとつなぐ。

    必要なのは Node.js 22以上と、ご自身のFirebaseプロジェクトだけ。データはすべて、あなたの環境に保存されます。

    1. 1

      ダウンロードして起動

      Firebaseの設定を .env.local に書いて起動します。

      git clone https://github.com/arrenem/opentax
cd opentax && npm install
cp .env.local.example .env.local
npm run dev
    2. 2

      AIエージェントとつなぐ

      OpenTaxの Agent接続 画面で接続用のトークンを発行し、AIに登録します。Claude Codeの場合はこちら。

      npm run mcp:build
claude mcp add \
  --env OPENTAX_BASE_URL=http://localhost:3000 \
  --env OPENTAX_AGENT_TOKEN=otk_... \
  --transport stdio opentax \
  -- node "$PWD/packages/opentax-mcp/dist/server.mjs"

      ClaudeやChatGPTのチャットからは、https://<あなたのOpenTax>/api/mcp をカスタムコネクタとして追加するだけで使えます。

    3. 3

      頼んで、確認する

      いつものAIに頼んだら、OpenTaxの確認画面で内容を見て確定します。申告データを出す前には、必ずご自身で見直してください。

      > 9月の銀行CSVを読んで、OpenTaxに記帳して。
  迷ったものはメモを付けて残しておいて。
