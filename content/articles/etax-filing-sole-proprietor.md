**e-Taxの確定申告は、帳簿を完成させ、決算書・申告書を作成し、本人が確認して送信する順に進めます。**

送信後は受信通知を確認し、控えを保存して、納付または還付の確認へ進みます。

国税庁の確定申告書等作成コーナーを使う場合の流れを、個人事業主向けにまとめます。

## 申告する年分と、帳簿・控除の資料をそろえる {#section-1}

「2026年に操作する」ことと「2026年分の所得を申告する」ことは別なので、最初に対象年分を決めます。

決算整理済みの帳簿、青色申告決算書または収支内訳書、源泉徴収された報酬の一覧が事業の主な資料です。

給与など事業以外の所得資料、社会保険料や保険料・寄附などの控除資料、還付を受ける場合の口座も別にそろえます。

消費税申告が必要な場合は、所得税と別の申告・納付として扱います。

| 準備するもの | 入力・確認に使う内容 |
| --- | --- |
| 決算整理後の帳簿・決算書 | 売上、経費、資産・負債、事業所得 |
| 報酬の請求・支払明細 | 収入と源泉徴収税額 |
| 給与など他の所得資料 | 事業以外の所得 |
| 保険料・寄附等の資料 | 所得控除・税額控除の該当項目 |
| マイナンバーカード等 | 本人認証・電子署名 |
| 還付先口座 | 還付を受ける場合の振込先 |

## マイナンバーカード方式の利用環境を準備する {#section-2}

国税庁の[個人向けe-Tax案内](https://www.e-tax.nta.go.jp/kojin.html)から、確定申告書等作成コーナーへ進めます。

案内に沿って、利用者識別番号の取得から申告書の作成・送信まで手続できますが、申告内容によって作成コーナーを使えない場合もあります。

[出典1](#sources)

マイナンバーカード方式では、カードと電子証明書の有効期限、暗証番号、対応端末、必要なアプリを確認します。

パソコンで入力し、スマートフォンを認証に使う方法もあるため、自分の端末に合う公式の案内を使います。

暗証番号や個人番号は、帳簿の共有資料やAIへの仕訳依頼には含めません。

ID・パスワード方式は新規発行停止が案内され、令和9年分（2027年分）確定申告から利用できなくなる予定です。

[出典2](#sources)

既存のIDがあっても、今後もずっと同じ方式を使える前提にはせず、カード方式の準備につなげます。

## 決算書の数字から事業所得を入力する {#section-3}

対象年分と提出方法を選び、事業に合う決算書または収支内訳書を作ります。

事業の売上、経費、減価償却は、銀行の入出金合計ではなく決算整理後の帳簿を使います。

売上3,600,000円、必要経費1,000,000円の例なら、青色申告特別控除前の所得は2,600,000円です。

青色申告特別控除は要件に合った額を適用し、その後に給与など他の所得と所得控除・税額控除を入力します。

この2,600,000円は帳簿の利益の例で、最終の申告税額を示すものではありません。

源泉税は取引先別の年間集計と照合し、報酬の経費として差し引かず、税額の項目へ引き継ぎます。

マイナポータル等で取得した控除資料を使う場合も、手入力済みの同じ資料を重ねて計上しないよう確認します。

## 送信前は、プレビューと元資料を見比べる {#section-4}

確認するのは、年分、氏名等、事業所得、事業以外の所得、源泉税、各種控除、添付する決算書、還付先口座です。

帳簿で直した数字がある場合は、決算書と申告書の両方へ反映されたかを見ます。

途中保存した作成データは再開用で、保存しただけでは税務署へ提出されません。

本人が内容を確認し、公式画面の認証・署名の案内に沿って送信します。

## 受信通知を確認し、提出した控えを保存する {#section-5}

送信直後には、受付日時や受付番号などを示す即時通知が表示されます。

その後、メッセージボックスに入る受信通知で受付結果を確認します。

[出典3](#sources)

受信通知には基本事項や電子証明書等のチェック結果が含まれるため、送信ボタンを押したという記憶だけで完了としません。

即時通知や受信通知にエラーがある場合は、内容を確認して必要な訂正や再送信などを行います。

申告書、決算書、受信通知を同じ年分で保存し、修正して再送した場合はどれが最後に受け付けられた控えかを分かるようにします。

## 納付・還付は、送信とは別に確認する {#section-6}

納税額がある場合、申告書の送信だけで支払いまで済むとは限りません。

納付方法、期限、申込みが必要な手続、引落口座の残高などを確認し、支払状況を残します。

還付の場合は口座情報が正しいことを確かめ、その後の処理状況と入金を確認します。

| 完了を分ける項目 | 残す記録 |
| --- | --- |
| 申告書を送った | 送信日時・受付番号 |
| 受付結果を確認した | 受信通知・エラーの有無 |
| 控えを保存した | 申告書・決算書・必要な添付資料 |
| 納付・還付を確認した | 支払完了、引落予定、還付状況など |

## 2026年分の画面・最終案内について {#section-7}

2026年10月3日時点で、国税庁は令和8年分の申告書を掲載し、今後変更する場合があると案内しています。

[出典4](#sources)

本記事では準備から完了確認までを説明し、2026年分の最終画面のボタン位置、最終手引き、申告期の受付・納付日程を確認済みとはしていません。

実際の申告には対象年分の公式案内を使い、2025年分の画面例をそのまま2026年分の手順として扱わないことが必要です。

青色申告決算書の数字を先に整理したい場合は、[帳簿から各欄へ移す記入例](/articles/blue-return-financial-statements-howto)を参照できます。

## 申告に使う帳簿をOpenTaxで整える {#section-8}

e-Taxへ進む前の記帳や残高確認には、OpenTaxを使う方法があります。

連携したAIが領収書や明細を読み取り、人が確認待ちの仕訳を確かめて確定し、損益計算書・貸借対照表を確認できます。

普段から未入金、カードの未払い、固定資産を整理しておけば、申告時に資料から一年分を作り直す負担を減らせます。

OpenTaxのe-Tax用ファイル出力は対応範囲が限られ、出力後は対象年分のe-Taxソフト等で内容を確認する必要があります。

国税庁の作成コーナーへどの出力ファイルでもそのまま読み込める、という意味ではありません。

ソフト本体は無料で、AIサービスや保存先の費用が別にかかる場合があります。
