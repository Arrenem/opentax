**銀行明細の同期、税理士との共同作業、申告書の作成までまとめたいなら、freee会計が候補です。**

普段のChatGPTやClaudeへ記帳を依頼し、自分で仕訳を確認しながらソフト代を抑えたいなら、OpenTaxが候補になります。

この記事はOpenTaxの開発元が、両製品の公開資料をもとに編集しています。

## freeeは申告までのサービス、OpenTaxはAIと使う帳簿 {#comparison}

freee会計は、提供会社のWebサービスへ登録して使います。

OpenTaxは、個人事業主向けに開発中のオープンソース会計ソフトで、自分の運用環境へ置いてブラウザやAIから使う方式です。

| 比べること | freee会計・個人向け | OpenTax |
| --- | --- | --- |
| 日々の記帳 | 手入力、銀行・カード明細の取り込み | 手入力、連携したAIからの記帳 |
| AIとの分担 | 製品内の入力支援や連携機能を利用 | ChatGPTやClaudeが解釈、OpenTaxが検証・記録 |
| 仕訳の確認 | 登録内容を確認・修正 | AI登録は確認待ちにし、人が画面で確定 |
| 帳簿・レポート | 仕訳帳、元帳、試算表など | 複式帳簿、損益計算書・貸借対照表など |
| 請求・証憑・固定資産 | プランの範囲で対応 | 見積書・請求書、証憑保管、固定資産に対応 |
| 税理士との共有 | アドバイザー制度とプランに応じた招待 | 共同作業向けの権限管理は未対応 |
| 所得税の申告 | スターターから申告書作成に対応 | 税額プレビューと一部内容のe-Tax用ファイル出力 |
| 消費税申告 | スタンダード以上 | 消費税の申告・提出は別の手段で行う前提 |

※2026年10月3日確認の公開仕様による比較で、両製品を同一条件で実測した結果ではありません。

### 銀行の同期を重視するなら、freeeの対応口座を軸にする {#section-2}

freeeは、銀行やクレジットカードの明細を取り込んで記帳に使えます。

利用する銀行・カードが対応していれば、定期的に明細を集める作業をまとめやすくなります。

OpenTaxでは、AIが受け取った銀行明細を読んで記帳を依頼できますが、銀行の常時自動同期と同じ仕組みではありません。

そのため、今使っている同期をそのまま残したい人は、料金だけでなく、明細を集める手順まで比べると違いが分かります。

### OpenTaxは、AIと人の担当が分かれている {#section-3}

OpenTax自身が領収書を読み取ったり、勘定科目を自動判断したりするわけではありません。

内容を解釈するのは接続したAIで、OpenTaxは受け取った記帳内容を検証して帳簿へ記録します。

AIの登録した仕訳は確認待ちになり、人が画面で金額・科目・税区分を確認してから確定します。

普段のAIへの依頼と、自分が確かめる帳簿をつなげられるのが特徴です。

### 申告まで任せる範囲には違いがある {#section-4}

freeeはスターターから所得税申告書と青色申告決算書を作成でき、消費税申告はスタンダード以上で使えます。

OpenTaxの現行対象は、暦年で管理する個人事業の事業所得です。

給与所得などとの合算、損益通算、純損失の繰越控除は対象外で、税額プレビューは確認用の参考値です。

e-Tax用ファイル出力も青色申告決算書の一般用と確定申告書の一部に相当する内容なので、出力後はe-Taxソフト等で内容を確認し、申告全体を仕上げます。

## 費用は、freeeの年額とOpenTaxの外部費用を比べる {#cost}

| 費用 | freee会計 | OpenTax |
| --- | --- | --- |
| ソフトの利用料 | スターター年11,760円、スタンダード年23,760円 | 本体無料 |
| 月払い | スターター月1,780円、スタンダード月2,980円 | 本体の月額契約なし |
| 保存先 | 契約内の容量・条件による | Firebaseなどの保存先費用がかかる場合あり |
| 外部AI | 利用する連携による | 接続するChatGPT・Claudeなどの契約による |
| 税理士との共同作業 | 招待条件とプランに応じる | 帳簿の受け渡し方法を別に決める |

※freeeはWeb契約の通常料金、税抜です。

freeeを通年使う場合、スターターの月払い12回は21,360円なので、年払いへ変えるだけで9,600円安くなります。

まず費用を下げたいだけなら、[freeeの料金を見直す方法](/articles/freee-cost-review)が、移行せずにできる選択です。

OpenTaxは本体無料ですが、保存量や外部AIの利用状況によって支出が変わるため、全員の年間費用が0円になるという比較にはしていません。

一方、すでに使っているAIと帳簿をつなぎたい人は、既存のAI契約と必要な保存費用を含めて考えられます。

## 乗り換えるなら、請求と入金の3件から確かめる {#migration}

実際のデータを移す前に、売上30,000円、翌月の入金30,000円、個人が立て替えた消耗品2,000円の3件を比べると、移行後の帳簿を確認しやすくなります。

税や手数料を含めない架空例なら、結果は次のようになります。

| 確認する数字 | 3件を記帳したあとの状態 |
| --- | ---: |
| 売上 | 30,000円 |
| 売掛金 | 入金後は0円 |
| 消耗品費 | 2,000円 |
| 事業主借 | 2,000円 |

入金をもう一度売上として登録すると60,000円になるので、この照合だけでも二重計上を見つけられます。

帳簿の取引日・科目・税区分・摘要と、元の領収書へ戻れることも比べます。

OpenTaxにfreeeのCSVを無加工で直接取り込めることは、この比較では確認していません。

本番では旧帳簿を残し、開始残高と移行月の残高を照合する手順が必要です。

仕訳だけでなく、証憑や固定資産、未入金の情報まで移す準備は、[freeeから乗り換える前のチェックリスト](/articles/switch-from-freee)で整理しています。

## 普段のAIへ記帳を頼みたい方へ {#opentax}

領収書や明細の入力をAIに頼み、最後は自分で確認して帳簿へ残す使い方を選ぶなら、OpenTaxが向いています。

**本体無料で、AIとの記帳、損益計算書・貸借対照表、見積書・請求書、証憑保管、固定資産をまとめられます。**

ソフト代を抑えながら、毎日の経理を普段のAIと一緒に進めたい方の選択肢です。
