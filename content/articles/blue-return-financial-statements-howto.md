**青色申告決算書は、決算整理が終わった帳簿から、売上・経費・資産・負債をまとめて作ります。**

銀行の入出金合計をそのまま移すのではなく、未入金や未払い、減価償却、家事按分を反映した数字を使います。

ここでは一般用の決算書を、売上3,600,000円・経費1,000,000円のサービス業の例で説明します。

## 使う年分と一般用の書類を確認する {#section-1}

一般用は通常の事業所得向けで、不動産所得用・農業所得用などとは様式が異なります。

前年の決算書、期首残高、決算整理後の試算表、月別売上、未入金・未払一覧、固定資産台帳が主な準備資料です。

本記事のページ構成は、確認済みの令和7年分（2025年分）の国税庁手引き・様式に基づきます。

[出典1・2](#sources)

2026年10月3日時点の国税庁掲載案内では、令和8年分申告書に変更の可能性が明記され、2026年分の最終手引き・入力画面は未確認です。

## 1ページ目の損益は、科目別の年間合計から作る {#section-2}

商品仕入や専従者給与がない、税込経理のサービス業の架空例です。

| 科目・集計 | 帳簿から移す金額 |
| --- | ---: |
| 売上 | 3,600,000円 |
| 通信費 | 120,000円 |
| 地代家賃 | 360,000円 |
| 旅費交通費 | 90,000円 |
| 消耗品費 | 80,000円 |
| 減価償却費 | 60,000円 |
| その他必要経費の合計 | 290,000円 |
| 必要経費の合計 | 1,000,000円 |
| 青色申告特別控除前の所得 | 2,600,000円 |

経費は120,000＋360,000＋90,000＋80,000＋60,000＋290,000＝1,000,000円です。

売上3,600,000円から差し引くと、控除前所得は2,600,000円になります。

表の「その他必要経費」は説明のための合計で、実際の決算書では広告宣伝費、外注工賃など該当する科目へ分けます。

私用出金や借入金元本の返済は経費に混ぜず、家事按分した後の事業分を使います。

銀行入金には前年の売掛金回収や個人資金の補充が含まれる一方、当年の未入金売上は入っていないことがあるため、売上元帳から集計します。

## 月別売上と各種明細を、損益の合計へつなぐ {#section-3}

2ページ目の月別売上は、1月1日から12月31日までの月別合計を記載します。

[出典1](#sources)

毎月300,000円という例なら、300,000×12＝3,600,000円で1ページ目の売上と一致します。

月中締めの請求一覧を使っている場合も、年末に計上した未入金売上などを含めて一年分へそろえます。

地代家賃の明細では、支払総額と必要経費に入れる事業分を区別します。

減価償却の明細は、取得価額、取得年月、方法、耐用年数、使用月数、償却額、事業割合、経費算入額、期末残高を固定資産台帳から移します。

共用資産の償却額が75,000円、事業割合80％なら、損益へ移す必要経費は60,000円です。

この60,000円を、上の経費表の減価償却費と一致させます。

給与や専従者給与、利子割引料などの明細が必要な場合も、対応する帳簿の内訳から記載します。

## 貸借対照表は、期首と期末を別々に埋める {#section-4}

期首残高は原則として前年末からの引継ぎ、期末残高は今年の決算整理後の帳簿です。

現金・預金600,000円、売掛金300,000円、工具器具備品200,000円なら、これらの資産は合計1,100,000円です。

未払金が100,000円の場合、その差1,000,000円をすべて元入金にするのではなく、元入金・事業主貸・借・控除前所得の関係で説明します。

たとえば元入金500,000円、事業主借100,000円、事業主貸2,200,000円、控除前所得2,600,000円だった場合、決算書の期末欄は次のようにつながります。

| 資産の部に記載するもの | 金額 | 負債・資本の部に記載するもの | 金額 |
| --- | ---: | --- | ---: |
| 現金・預金 | 600,000円 | 未払金 | 100,000円 |
| 売掛金 | 300,000円 | 事業主借 | 100,000円 |
| 工具器具備品 | 200,000円 | 元入金 | 500,000円 |
| 事業主貸 | 2,200,000円 | 青色申告特別控除前の所得 | 2,600,000円 |
| 合計 | 3,300,000円 | 合計 | 3,300,000円 |

事業主貸は、決算書の様式では資産の部に記載する欄があります。

[出典2](#sources)

事業に残る資産1,100,000円と、様式上の合計3,300,000円を混同しないことがポイントです。

左右が合わないときは、転記漏れ、期首残高、決算整理の未反映を調べ、差額を元入金に足して合わせません。

## 控除後の所得を、確定申告書へ引き継ぐ {#section-5}

青色申告特別控除は55万円・65万円・10万円の区分があり、記帳方法や決算書の添付、期限内申告などの要件で決まります。

[出典3](#sources)

65万円は55万円の要件に加え、期限内に申告書・決算書等をe-Taxで送信するか、所定の優良な電子帳簿の要件を満たす必要があります。

この事業所得だけの例で65万円控除の要件を満たすなら、2,600,000−650,000＝1,950,000円が控除後の所得です。

申告書では、これに他の所得や所得控除などを反映するため、1,950,000円がそのまま最終の課税所得や税額になるわけではありません。

報酬から引かれた源泉税も、所得額とは別に集計して引き継ぎます。

決算書から申告書へ数字を引き継いだ後は、[e-Taxの送信と受付確認](/articles/etax-filing-sole-proprietor)を行います。

## OpenTaxの帳簿とレポートを決算書の根拠にする {#section-6}

OpenTaxは記帳データから損益計算書・貸借対照表を確認でき、固定資産の管理にも使えます。

AIが資料を解釈して登録した仕訳は、人が確認して確定してから集計の根拠にします。

この例なら売上3,600,000円、経費1,000,000円、売掛金300,000円などを資料や明細と照合し、決算書へつなぐ使い方です。

e-Tax用ファイル出力は青色申告決算書一般用と確定申告書の一部が対象で、年度ごとの仕様と読込後の内容確認が必要です。

2026年分の最終様式への対応や読込成功を、本記事で検証したものではありません。

ソフト本体は無料で、AIサービスや保存先の料金が別にかかる場合があります。
