**マネーフォワード クラウド確定申告は、未契約でも1会計年度50件まで仕訳を登録できます。**

ただし、事業所得を申告する個人事業主は、無料のまま確定申告書や青色申告決算書を出力・提出することはできません。

1か月の無料トライアルも申告書出力は原則対象外なので、記帳を試すことと、申告まで終えることを分けて考えましょう。

## 無料トライアルと未契約では、使える機能が違う {#free-range}

初めて利用する人が使える1か月の無料トライアルは、個人向けのパーソナル相当の機能を試す期間です。

過去に有料契約の履歴がない事業者が対象で、利用は1事業者につき1回です。

終了後は自動的に未契約へ移り、申し込まない限り有料契約にはなりません。

期間中に登録したデータは、未契約になったあとも保持されます。

| 作業 | 1か月トライアル | 未契約での無償利用 |
| --- | --- | --- |
| 仕訳の登録 | パーソナル相当 | 1会計年度50件まで |
| 帳簿・残高試算表などの閲覧とPDF | 利用可能 | 利用可能 |
| 各種CSV出力 | パーソナル相当の機能を試せる | 利用不可 |
| 証憑の添付・連携明細の手動取得 | 試用対象 | 利用不可 |
| 事業所得の申告書のプレビュー・PDF・e-Tax用ファイルの出力・提出 | 原則利用不可 | 利用不可 |

※2026年10月3日確認の通常条件です。

※無償利用では補助元帳のPDF一括出力も対象外です。

[出典1・2・3](#sources)

トライアルでも事業所得の申告書出力は対象外ですが、クラウドパートナー利用の士業から顧問先登録されている場合や、対象クーポンを適用している場合には例外があります。

一般の無料登録だけでこの例外が使えるわけではありません。

また、家計簿アプリの「マネーフォワード ME」は別サービスです。

MEの有料・無料の区分では、クラウド確定申告の利用条件は決まりません。

### 「決算書PDF」と「青色申告決算書」は区別する {#section-2}

未契約でも、帳簿画面の決算書を閲覧してPDFにする機能は使えます。

一方、確定申告機能で作る青色申告決算書・収支内訳書と、確定申告書のプレビューや出力は、事業所得を申告する場合には使えません。

似た名前の書類でも役割が違うため、「決算書が出せたから提出書類も無料」とは判断できません。

雑所得や控除だけを申告する場合には無料利用の例外がありますが、この記事で扱う事業所得の申告には、そのまま当てはまりません。

## 年間50件は、請求書の枚数で数えない {#count}

月4枚の請求書を発行する人でも、年間の仕訳が48件で済むとは限りません。

請求時に売上を計上し、翌月の入金時に売掛金を消すなら、請求と入金は別の記録になります。

カード払いの経費も、購入時と銀行からの引き落とし時を分けて処理することがあります。

たとえば、次のような運用をすると、一月の記帳は13件になります。

| 毎月記録するもの | 件数の例 |
| --- | ---: |
| 売上の計上 | 4件 |
| 売掛金の入金 | 4件 |
| 経費 | 5件 |
| 一月の合計 | 13件 |
| 同じ取引量の12か月分 | 156件 |

これは必要な記録量を見積もる架空例で、複合仕訳などを含む公式の件数カウント仕様そのものではありません。

実際の登録件数表示を見ながら、普段の一月分を試すと上限との距離が分かります。

無料枠へ収めるために必要な売上や経費を省くのではなく、記録する量に合う契約や道具を選びましょう。

## 申告書とCSVは、必要な有料プランが違う {#paid}

所得税の申告書を作成・出力したいだけなら、最安のパーソナルミニも候補です。

ただし、仕訳帳のCSV・MF形式出力、消費税申告、メンバー追加はパーソナル以上の機能です。

税理士へCSVを渡したい人は、「無料では出せないから最安プランへ」というだけでは目的を満たせません。

2026年10月時点のWeb契約では、ミニは月1,280円・年10,800円、パーソナルは月1,680円・年15,360円です。

いずれも税抜で、12月1日には一部料金が改定される予定です。

料金改定と更新日の関係は、[マネーフォワードの料金を安くする方法](/articles/moneyforward-cost-review)で現行と改定後を並べています。

スマホ中心で使う場合は、無料のアプリに領収書などの画像読取（AI-OCR）、証憑添付、消費税電子申告などの制限もあります。

乗り換えが目的の人は、[マネーフォワードから移す帳簿と資料](/articles/switch-from-moneyforward)を先にそろえると、契約終了後の取り出しで困りにくくなります。

## 日々の記帳を無料のソフトで続けたいなら {#opentax}

年間50件では足りず、記帳のために毎年料金を払うのを抑えたい方には、OpenTaxも候補です。

**OpenTaxはソフト本体無料で、普段使っているChatGPTやClaudeから記帳を依頼できます。**

AIが領収書や明細を読み取ってOpenTaxへ記録し、登録された仕訳は人が確認してから確定します。

帳簿と損益計算書・貸借対照表の確認だけでなく、見積書・請求書、証憑の保管、固定資産の管理にも使えます。

個人事業の事業所得を対象に、日々の入力と確認を続けるための道具になります。

※保存先や連携するAIサービスには、別途費用がかかる場合があります。
