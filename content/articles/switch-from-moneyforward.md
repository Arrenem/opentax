マネーフォワード クラウド確定申告から別の会計ソフトへ移るときは、現在の個人向けプランで必要な形式を出せるかを最初に確認します。年度、出力形式、証憑、残高をそろえ、小さく取り込みを試してから本格的に切り替える手順が役立ちます。

## まず個人向け契約と出力条件を確認する

[確定申告の公式機能表](https://biz.moneyforward.com/support/tax-return/faq/price/p12.html)では、仕訳帳のCSV・MF形式出力はパーソナルとパーソナルプラスが対象です。無料状態だけでなく、パーソナルミニも対象外です。有料ならどのプランでも移行CSVを出せるとは考えず、現在の契約と必要な形式を照合してください。

[無償状態の公式説明](https://biz.moneyforward.com/support/plan/guide/p024.html)には、帳簿PDFの閲覧・出力ができる範囲と、各種CSV等の制限が分けて記載されています。契約を先に止めてからCSV出力へ進むと作業が止まることがあります。プラン変更が必要な場合は変更画面の適用日・費用を確認してから判断します。

## 出力前に年度ごとの保存一覧を作る

| 保存する内容 | 用途 |
| --- | --- |
| 仕訳CSV・MF形式 | 移行先で取り込むための候補、原本保全 |
| 仕訳帳・元帳PDF | 元の帳簿を読める形で残す |
| 残高試算表・決算書 | 取り込み前後の金額を照合する |
| 固定資産の一覧 | 取得日・取得価額・未償却残高を引き継ぐ |
| 申告書・決算書・送信結果 | 過去年分の提出控え |
| 領収書・請求書・明細 | 取引の証拠を別途残す |

今年度だけでなく必要な過年度も確認します。検索条件で表示できる年度の範囲と、事業者の会計年度切り替えを混同しないようにしてください。証憑がCSVへ画像として埋め込まれるとは限らないため、クラウドBox等に保管した実ファイルも保存方法を調べます。

## 仕訳帳のPDF・CSV・MF形式を選ぶ

[クラウド確定申告の公式仕訳帳手順](https://biz.moneyforward.com/support/tax-return/guide/books2/bo01.html)では、「会計帳簿」から仕訳帳を開き、エクスポートでPDF・CSV・MF形式を選べます。CSV形式とMF形式はどちらもCSVファイルですが、出力項目が異なります。MF形式は全項目、CSV形式は定められた項目の出力として説明されています。

他社形式での出力は「各種設定」の「他社ソフトデータの移行」から行う案内もあります。ファイル拡張子が同じ `.csv` でも仕様は同じではありません。移行先が受け付ける形式を確認して選び、保存用にはMF形式など元の情報を多く残せる出力も検討します。

操作前に対象年度・開始日・終了日を確認し、タグや金額の絞り込みを解除します。出力の直前に、画面上の件数と借方・貸方合計をメモしてください。残高試算表も同じ期間で保存しておきます。

## 少量のサンプルで列対応を試す

売上、カード経費、売掛金の入金、事業主貸借、複合仕訳を含む少数のサンプルを選びます。公開用の例や検証データには架空の相手・金額を使い、実際の帳簿を公開しないでください。

| 確認する対応 | 見るポイント |
| --- | --- |
| 勘定科目・補助科目 | 名前の違い、未登録科目、科目種別 |
| 税区分・インボイス関連 | 相当する区分へ対応しているか |
| 取引日・仕訳の組 | 日付変換、複合仕訳のまとまり |
| 摘要・タグ・メモ | 長さ・改行・文字コード・欠落 |
| 金額 | 税込/税抜、借方/貸方、端数 |

移行先にOpenTaxを選ぶ場合も、対応が確認できた形式・列だけを使います。この記事では未検証の自動変換や直接連携を前提にしません。候補製品の取り込み仕様とサンプル結果を確認し、元ファイルを保全したコピーで変換してください。

## 残高と履歴を照合して切り替える

仕訳の借方・貸方合計が一致していても、違う科目へ入れば残高が変わります。普通預金、売掛金、未払金、売上、主要経費を、元サービスと同じ日付の帳票で比較します。例えば未払金の残高が移行元30,000円、移行先0円なら、カード引落しや期首の未払残高が漏れていないかを調べます。原因を確認する前に調整仕訳で帳尻を合わせないでください。

前年末から移るなら期首残高、年の途中なら移行対象期間と開始残高を整理します。期首残高を別途入れた後に同じ残高を含むデータを取り込み、二重計上することがないようにします。銀行明細の自動取り込みも切替日を決め、同一期間を両方から重複登録しないよう管理しましょう。

最後に、すべての出力ファイルを開き、検算結果と未確認事項をメモに残します。元サービスの停止・解約は移行結果の確認後に、購入経路に応じた公式手順で行います。更新が近い人は[料金改定と見直し](/articles/moneyforward-cost-review)も確認し、移行に必要な出力期間を確保してください。
