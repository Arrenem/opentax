AIで仕訳候補を作るには、日付・金額・用途だけでなく、支払元とすでに記帳した取引との関係を渡します。銀行の摘要だけで分類させると、売掛金の回収を売上にしたり、カード引落しを二度目の経費にしたりする可能性があります。候補、根拠、保留理由を別々に出し、確認したものだけ帳簿へ反映する手順を作ります。

## 入力する最小項目と分類ルール

取引ID、取引日、内容、金額、事業目的、支払元、関連する請求書や過去仕訳のIDをそろえます。「A店3,000円」より「A店で仕事用の文具を私用財布から購入3,000円」の方が判断に必要な情報があります。実際の口座番号や顧客情報を入力する前に利用先の公式のデータ取扱いを確認し、練習は架空情報で行います。

同じ種類の支出に使う科目、税込・税抜の扱い、私用部分の区分、判定を保留する条件も先に決めます。高額な道具、契約の前払い、源泉徴収のある入金などは「金額だけで即確定しない」と指定します。取得した資産を毎回全額経費にすることはできず、処理は[国税庁の減価償却案内](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2100.htm)に照らして判断します。

## 候補と要確認理由を出す入力例

次は練習用の依頼文です。特定のモデルに実行して測定した結果ではありません。

```text
個人事業主の架空取引を分類してください。
出力は取引ID、借方候補、貸方候補、金額、根拠、追加確認事項。
税込経理の練習で、消費税の税区分はこの例では省略します。
根拠が不足する項目は確定せず「保留」としてください。
カード利用と銀行引落し、請求と入金の二重計上を避けてください。
T01: 仕事用文具2000円、事業現金払い、領収書あり。
T02: T00で売掛金50000円を計上済み。その全額が事業口座に入金。
T03: 当月通信代3000円、事業カード利用、引落し前。
T04: 前月に計上した未払金3000円が事業口座から引落し。
T05: 私用財布から業務交通費1000円、日付・区間・用務の記録あり。
```

## 10件の答え合わせと保留の扱い

| ID | 架空の内容 | 確認後の扱い |
| --- | --- | --- |
| T01 | 仕事用文具2,000円、現金 | 消耗品費／現金2,000 |
| T02 | 計上済み売掛金50,000円の回収 | 普通預金／売掛金50,000 |
| T03 | 通信代3,000円、カード | 通信費／未払金3,000 |
| T04 | 前月未払金3,000円の引落し | 未払金／普通預金3,000 |
| T05 | 業務交通費1,000円、私費 | 旅費交通費／事業主借1,000 |
| T06 | 事業口座から生活費20,000円 | 事業主貸／普通預金20,000 |
| T07 | 通信費10,000円、事業割合未確認 | 用途記録と按分根拠がそろうまで保留 |
| T08 | PC350,000円、購入日・使用開始日不明 | 資産区分、取得日、適用要件を確認するまで保留 |
| T09 | 外注先への入金89,790円、請求書なし | 請求総額・差引内容・取引関係を確認するまで保留 |
| T10 | T01と同じレシートの再送 | 重複候補として新しい仕訳を作らない |

T09の89,790円だけから源泉徴収額を逆算して断定しません。端数や別の相殺が含まれるかもしれず、そもそも入金・出金の説明を誤っている可能性もあります。不足を指摘できた項目は、無理に科目を決めるより有用です。

## 修正してから合計を確かめる

仮にT02の候補が「普通預金／売上」、T04が「通信費／普通預金」なら、請求時・利用時の仕訳を照合して上表へ修正します。元の候補、修正後、修正理由を残すと、次回の依頼ルールも改善できます。モデル名・利用日・入力文を記録する欄は用意しますが、本記事は実測前なので成功率や時短率を示しません。

確定したT01〜T06の金額合計は左右とも79,000円です。費用増加は2,000＋3,000＋1,000＝6,000円。T02の回収は売上を増やさず、T04の引落しは費用を増やさず、T06の生活費も費用に含めません。預金の増減は50,000−3,000−20,000＝27,000円となります。この区別を検算に使えます。

## 帳簿に反映する前のチェック

取引IDと原資料が結び付くか、保留を確定一覧へ混ぜていないか、既存仕訳と重複していないかを確認します。左右が同額でも事業目的や時期が誤っていれば修正が必要です。必要経費の時期と私用部分は[国税庁「必要経費の知識」](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm)で確認できます。

まずこの10件を自分の科目ルールに当てはめ、追加確認が必要な3件を言葉で説明してみてください。[複式簿記の基礎](/articles/double-entry-bookkeeping-howto)と[家事按分](/articles/business-use-expense-apportionment)を合わせて読むと、AIに渡す情報を具体化できます。

## 分類ルールを改善する記録の例

修正した候補には「摘要に入金とあるが、請求書を発行した段階で売上は記録済み」「私用財布から払ったので事業現金は減らさない」といった具体的な理由を添えます。その理由を次の依頼の条件に加えると、自分の帳簿の前提が伝わります。ただし一度正しく分類できたことを、すべての取引を正しく処理できる根拠にはしません。

金額や科目が似ている別取引を重複扱いにする誤りも考えられるため、日付、資料番号、取引先、購入内容を照合します。確定した仕訳からも元の候補と資料へ戻れるように管理してください。
