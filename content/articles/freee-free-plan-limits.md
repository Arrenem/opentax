freee会計の無料登録、お試し、未契約状態、freee請求書の無料機能は、それぞれ使える範囲が違います。個人事業主が知りたいのは、登録できるかだけでなく、帳簿を取り出し、事業所得の申告まで終えられるかです。作業ごとに条件を確認しましょう。

## 会計と請求書を分けて考える

freee請求書で請求書を無料作成できることから、freee会計の仕訳や確定申告もずっと無料だとは判断できません。請求書は取引相手へ渡す書類、仕訳帳は事業の帳簿、所得税の申告書は税務署へ提出する書類です。それぞれの製品名と契約状態を確認してください。

[個人向け公式プラン説明](https://support.freee.co.jp/hc/ja/articles/213726523)では、お試し終了後は自動的に未契約状態になり、利用機能が制限されます。お試しの日数は登録画面・契約画面に表示された終了日を控えると確実です。有料契約へ切り替えると、その日から課金が始まり、お試しの残り期間は消滅する扱いです。

## お試しで試す操作と残せるもの

| 操作 | 個人向けお試しの扱い |
| --- | --- |
| 取引の閲覧・編集 | 直近1か月に登録したデータが対象 |
| 仕訳帳・総勘定元帳のCSV/PDF | お試し{{pricing:freee-trial:journalExportLimitDisplay}}データのみ出力 |
| 取引データのCSV出力 | 利用不可 |
| 確定申告 | 内容入力まで。書類出力は有料契約の範囲 |

「画面に入力できた」と「完成した申告書を出力できた」を分けて確認してください。取引10件の試用出力は形式を確かめるには役立ちますが、一年分の帳簿バックアップの代わりにはなりません。

例えば、架空の売上1件、カード払いの経費1件、入金1件を登録すれば、入力方法と仕訳の見え方を試せます。自分の業務でよく発生する取引を少数選び、売上を入金時にも重ねて登録していないか、未払金の処理が分かるか、摘要が残るかを確認すると導入判断に役立ちます。大量の本番データを入れる前に、出力条件を確認する順序がおすすめです。

## 未契約になると変わること

同じ公式表では、未契約中の取引閲覧・編集、仕訳帳・総勘定元帳・取引CSV出力、確定申告機能、口座同期は利用不可とされています。ファイルボックスへの保存など一部操作が残っていても、無料の会計運用が完結するわけではありません。

新帳票機能のfreee請求書は未契約中でも作成・閲覧・編集ができる旨が説明されています。これは旧帳票や会計の取引閲覧まで利用できることを示す条件ではありません。請求書を作る画面と会計帳簿を見る画面を両方試し、自分が必要とする製品を取り違えないようにします。

## 試用終了前の確認メモ

| 確認欄 | 自分の記録例 |
| --- | --- |
| 無料状態の終了日 | 契約画面の日付を記録 |
| 実際に試した取引 | 売上、入金、カード経費 |
| 取り出す必要がある資料 | 仕訳CSV、帳簿PDF、証憑 |
| 有料契約が必要な目的 | 年間帳簿出力、申告書出力 |
| 契約経路 | Web、iOS、Androidを確認 |

無料範囲で目的を達成できないと分かったら、機能を増やす契約と、別の道具で作業する案の費用を比較します。試用が終わる直前に初めて制限へ気づくと、保存や入力方法の変更に時間がかかります。導入を決める段階で、申告までの流れを紙に書いておくと判断が安定します。

有料契約を停止する場合も、アプリを消すだけでは課金停止になりません。[公式の停止手順](https://support.freee.co.jp/hc/ja/articles/202848470)に従い、支払い済み期間の終了日を確かめます。再契約すればデータを使えることと、未契約中に閲覧できることは別なので、必要資料は契約中に出力しておきましょう。

料金を確認するなら[freee会計の費用見直し](/articles/freee-cost-review)、他の無料条件も並べるなら[無料会計ソフトの比較](/articles/free-accounting-software)へ進んでください。
