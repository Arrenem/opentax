# 公開ソースの境界

## このリポジトリに含めるもの

- OpenTax の会計アプリと API、共通の会計・税額計算
- MCP アダプターと接続用プラグイン
- アプリ単体で実行できるテストと架空の最小テストデータ
- セルフホスト、接続、アーキテクチャ、税制ルールなどの利用・開発ドキュメント

公式サイトの LP、記事本文・画像・編集データ、編集ツール、サイト生成・配信処理とその運用資料は、別の非公開ソースで管理します。アプリのビルド・テストにそれらを読み込む処理を追加しないでください。

## ローカルでの検査

```bash
npm ci
npm run source:check
npm test
npm run lint
npm run typecheck
npm run mcp:build
npm run build
```

`source:check` は Node.js 標準機能だけで実行でき、依存パッケージを入れる前にも使えます。既知のマーケティング用パス、アプリから記事データへの参照、サイト専用 npm スクリプト・依存関係、サイト配信 workflow の再追加を検出します。依存パッケージ、Git 管理情報、通常のビルド成果物は検査対象外です。ファイルを任意の名前に変更した内容まで自動分類するものではないため、レビューでも公開範囲を確認してください。

会計の回帰テストは `lib/accounting/aggregationFixtures.ts` の架空仕訳と、アプリ内の計算テストを使用します。記事原稿や編集用 ID は不要です。

## CI と配信

[App CI](../.github/workflows/app-ci.yml) は公開ソースの境界、アプリと MCP のテスト、lint、型検査、MCP ビルドを検証します。配信処理や本番用の認証情報は持ちません。アプリの本番ビルドとセルフホストの手順は [セルフホストガイド](self-hosting.md) を参照してください。

この分離は今後このリポジトリで管理するソースの範囲を定めるものです。既存の [LICENSE](../LICENSE) は変更しません。
