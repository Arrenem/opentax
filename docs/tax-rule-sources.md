# 税制ルールと出典

OpenTax が実装している会計・税額計算のルールと、その実装場所・参照した資料の一覧です。計算はすべて決定的なコードで行い、`lib/tax/taxEngine.test.ts` などのテストで検証しています。

誤りや法改正への未対応を見つけた場合は、[コントリビューションガイド](../CONTRIBUTING.md) に沿って Issue で教えてください。出典（法令・通達・国税庁の資料）を添えていただけると大変助かります。

> [!NOTE]
> 対象は **個人事業主（暦年課税）** です。法人や、不動産所得・給与所得などとの複合的な申告は対象外です。詳しくは [既知の制限事項](../KNOWN_LIMITATIONS.md) を参照してください。

## e-Tax 用ファイル出力

| 内容 | 実装 | 備考 |
| --- | --- | --- |
| 青色申告決算書（一般用、帳票コード `HOB13000`）の XTX | `lib/export/xtxGenerator.ts` | 出力前に損益と貸借の整合性をチェックします。 |
| 確定申告書に相当する XTX 断片 | `lib/export/formBGenerator.ts` | |

e-Tax の XML スキーマや帳票仕様は、国税庁の「e-Tax 仕様書」に基づきます。仕様は年分ごとに改訂されるため、出力したファイルは e-Tax ソフト等で内容を必ず確認してください。

## 年分ごとのルールの管理

年分によって変わる値は `lib/tax/taxYearRules.ts` と `lib/accounting/periodConfig.ts` に集約し、コード中に日付や金額を直接書かない方針です。税制改正に対応する場合は、これらのファイルとテストを更新し、このドキュメントの出典も更新してください。
